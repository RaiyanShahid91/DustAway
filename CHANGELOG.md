# Changelog

## 0.1.0

First release.

- `Modifier.disintegrate(state)` and `DisintegrationState` (`disintegrate`, `restore`, `snapTo`).
- `DisintegrateVisibility` for dismiss-and-remove.
- `DustConfig`: duration, direction, sweep, wind, scatter, wobble, particle cap, seed.
- On-device Compose tests for the library and the sample app.
- Android-free `DustEngine` / `DustParticles`, covered by unit tests.
- Sample app with a playground, an image/card/whole-screen tab and a dismissable list.
