Jetpack Compose · Android

Make any composable turn to dust

One modifier. Cards, images, whole screens and list items crumble into drifting particles, then come back.

implementation("com.raiyanshahid:dustaway:0.1.0")

See every effect

Each preview is rendered with the library's own particle engine. Pick one to see it and the code behind it.

Use it in 3 steps

Works with minSdk 24 and Compose UI 1.7 or newer.

1. Add the dependency

Add JitPack, then the library.

// settings.gradle.kts
maven("https://jitpack.io")

// app/build.gradle.kts
implementation("com.raiyanshahid:dustaway:0.1.0")

2. Attach the modifier

Create a state and put it on any composable.

val state = rememberDisintegrationState()

Card(Modifier.disintegrate(state)) {
    Text("Gone in a moment")
}

3. Trigger it

Call it from a coroutine.

scope.launch { state.disintegrate() }
scope.launch { state.restore() }
